## 2. Inverter Candidate Legend & Provenance

* **Candidate 1 (Naive 11-Channel Sum, 234 kW peak):** Flawed reference including all PVDAQ channels; double-counts string currents alongside combiner inverter feeds.
* **Candidate 2 (De-duplicated Full Array, 185 kW peak):** De-duplicated summation removing duplicate combiners.
* **Candidate 3 (Triple Combiners, 115 kW peak):** Aggregates channels `inv04 + inv09 + inv10`.
* **Candidate 4 (String Sub-Array, 65 kW peak):** Sub-array grouping of 6 individual strings.
* **Candidate 5 (Twin Combiners, 86.9 kW peak):** Aggregates `inv04 + inv10`; matches the standard 1.25 Inverter Loading Ratio (ILR) for the 110 kW DC system.
