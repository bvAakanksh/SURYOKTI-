## 2. Reproduction Commands

To retrain models and regenerate figures:

```powershell
# 1. Regenerate 8-stage hybrid model evaluation suite
python plots/energy_prediction/hybrid_model_plots.py

# 2. Regenerate baseline exploratory figures
python plots/energy_prediction/plots.py

# 3. Regenerate Maui regional adaptation figures
python plots/energy_prediction/generate_energy_plots.py
```
